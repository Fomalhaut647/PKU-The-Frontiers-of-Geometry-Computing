\section{Task 1: 从深度图生成点云}

\subsection{算法描述}

给定深度图像素坐标 $(u, v)$ 和对应深度值 $z$，首先利用相机内参将其转换到相机坐标系：
\begin{equation}
    \begin{bmatrix} x \\ y \\ z \end{bmatrix} = z \begin{bmatrix} 1/f_x & 0 & -c_x/f_x \\ 0 & 1/f_y & -c_y/f_y \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix}
\end{equation}

即：
\begin{equation}
    x = \frac{(u - c_x) \cdot z}{f_x}, \quad y = \frac{(v - c_y) \cdot z}{f_y}
\end{equation}

然后利用相机位姿矩阵 $T_{cw}$（camera-to-world）将相机坐标转换为世界坐标：
\begin{equation}
    \mathbf{p}_w = T_{cw} \begin{bmatrix} x \\ y \\ z \\ 1 \end{bmatrix}
\end{equation}

\subsection{实现}

\begin{lstlisting}
def cam_to_world(depth_im, cam_intr, cam_pose, export_pc=False):
    H, W = depth_im.shape
    fx, fy = cam_intr[0, 0], cam_intr[1, 1]
    cx, cy = cam_intr[0, 2], cam_intr[1, 2]

    u, v = np.meshgrid(np.arange(W), np.arange(H))
    z = depth_im
    valid = z > 0
    u, v, z = u[valid], v[valid], z[valid]

    x = (u - cx) * z / fx
    y = (v - cy) * z / fy
    cam_pts = np.stack([x, y, z], axis=-1)

    cam_pts_h = np.concatenate(
        [cam_pts, np.ones((cam_pts.shape[0], 1))], axis=1)
    world_pts = (cam_pose @ cam_pts_h.T).T[:, :3]
    return world_pts
\end{lstlisting}

在 \texttt{demo.py} 中，遍历所有帧的点云，取各轴的最小/最大值确定体素场范围 \texttt{vol\_bnds}。

\section{Task 2: 从深度图采样}

\subsection{算法描述}

本步骤将 TSDF 体素场的采样点投影到深度图上进行深度采样，是 Task 1 的逆过程。具体步骤：

\begin{enumerate}
    \item \textbf{建立体素网格}：根据体素场范围 \texttt{vol\_bnds} 和体素尺寸 \texttt{voxel\_size}（2cm），计算各轴方向的体素数量 $\text{dim}_i = \lceil (\text{max}_i - \text{min}_i) / \text{voxel\_size} \rceil$，建立整数坐标网格。
    \item \textbf{体素坐标 $\to$ 世界坐标}：$\mathbf{p}_w = \text{origin} + \text{vox\_coords} \times \text{voxel\_size}$
    \item \textbf{世界坐标 $\to$ 相机坐标}：$\mathbf{p}_c = T_{cw}^{-1} \mathbf{p}_w$
    \item \textbf{相机坐标 $\to$ 像素坐标}：$u = f_x \cdot x/z + c_x$，$v = f_y \cdot y/z + c_y$
    \item \textbf{深度采样}：对落在图片范围内且 $z > 0$ 的体素点，从深度图上采样对应深度值。
\end{enumerate}

\subsection{实现}

初始化部分：
\begin{lstlisting}
self._vol_dim = np.ceil(
    (vol_bnds[:, 1] - vol_bnds[:, 0]) / self.voxel_size
).astype(int)
self._vol_origin = vol_bnds[:, 0]
self.tsdf_vol = np.ones(self._vol_dim)
self.weight_vol = np.zeros(self._vol_dim)
self.color_vol = np.zeros((*self._vol_dim, 3))

xv, yv, zv = np.meshgrid(
    np.arange(self._vol_dim[0]),
    np.arange(self._vol_dim[1]),
    np.arange(self._vol_dim[2]),
    indexing='ij')
self.vox_coords = np.stack([xv, yv, zv], axis=-1).reshape(-1, 3)
\end{lstlisting}

投影与采样部分（在 \texttt{integrate} 方法中）：
\begin{lstlisting}
# Voxel -> world -> camera coordinates
world_pts = self._vol_origin + self.vox_coords * self.voxel_size
world_pts_h = np.concatenate(
    [world_pts, np.ones((world_pts.shape[0], 1))], axis=1)
cam_pts = (np.linalg.inv(cam_pose) @ world_pts_h.T).T
cam_z = cam_pts[:, 2]

# Camera -> pixel coordinates
pix_x = np.round(fx * cam_pts[:, 0] / cam_z + cx).astype(int)
pix_y = np.round(fy * cam_pts[:, 1] / cam_z + cy).astype(int)

# Filter valid pixels and sample depth
valid = (pix_x >= 0) & (pix_x < im_w) \
      & (pix_y >= 0) & (pix_y < im_h) & (cam_z > 0)
depth_val = depth_im[pix_y[valid_idx], pix_x[valid_idx]]
\end{lstlisting}

\section{Task 3: 计算单帧 TSDF}

\subsection{算法描述}

对于每个有效的体素采样点，根据其在相机坐标系下的 $z$ 值和深度图上采样得到的深度值 $d$，计算 TSDF 值：
\begin{equation}
    \text{TSDF} = \min\left(1.0,\ \frac{d - z}{t}\right)
\end{equation}
其中 $t$ 为截断距离（truncation margin），设为 $5 \times \text{voxel\_size} = 0.1$ m。

TSDF 的物理含义：
\begin{itemize}
    \item $\text{TSDF} > 0$：该点在表面前方（相机侧）
    \item $\text{TSDF} < 0$：该点在表面后方
    \item $\text{TSDF} = 0$：该点恰好在表面上
\end{itemize}

只保留 $\text{TSDF} \geq -1.0$ 的体素点，丢弃距离表面过远的点。

\subsection{实现}

\begin{lstlisting}
tsdf = np.minimum(1.0,
    (depth_val - cam_z[valid_idx]) / self.trunc_margin)
valid_tsdf = tsdf >= -1.0
valid_idx = valid_idx[valid_tsdf]
tsdf = tsdf[valid_tsdf]
\end{lstlisting}

\section{Task 4: 融合多帧 TSDF 并提取 Mesh}

\subsection{算法描述}

将多帧 TSDF 通过加权平均方式融合。设第 $i$ 帧的 TSDF 值为 $d_i(x)$，对应权重为 $w_i$，则融合公式为：
\begin{equation}
    D_{i+1}(x) = \frac{W_i(x) \cdot D_i(x) + w_{i+1} \cdot d_{i+1}(x)}{W_i(x) + w_{i+1}}
\end{equation}
\begin{equation}
    W_{i+1}(x) = W_i(x) + w_{i+1}
\end{equation}

所有帧融合完成后，使用 Marching Cubes 算法在 TSDF 场的零等值面处提取三角网格。Marching Cubes 通过遍历每个体素，根据 8 个顶点的 TSDF 正负号确定等值面与体素边的交点，进而构建三角面片。这里直接调用 \texttt{skimage.measure.marching\_cubes} 实现。

\subsection{实现}

融合部分：
\begin{lstlisting}
w_old = self.weight_vol[vx, vy, vz]
d_old = self.tsdf_vol[vx, vy, vz]
w_new = w_old + obs_weight
self.tsdf_vol[vx, vy, vz] = \
    (w_old * d_old + obs_weight * tsdf) / w_new
self.weight_vol[vx, vy, vz] = w_new
\end{lstlisting}

Mesh 提取部分（在 \texttt{demo.py} 中）：
\begin{lstlisting}
verts, faces, normals, _ = measure.marching_cubes(
    tsdf_vol.tsdf_vol, level=0)
verts = verts * tsdf_vol.voxel_size + tsdf_vol._vol_origin
mesh = trimesh.Trimesh(vertices=verts, faces=faces,
                       vertex_normals=normals)
mesh.export("mesh.ply")
\end{lstlisting}

\section{附加任务: 带颜色的 TSDF Fusion}

\subsection{算法描述}

在 TSDF 融合的同时，对颜色信息也进行加权平均融合。对于每个有效体素点，从当前帧的彩色图上采样颜色值（使用与深度采样相同的像素坐标），然后使用与 TSDF 融合相同的权重进行加权平均：
\begin{equation}
    C_{i+1}(x) = \frac{W_i(x) \cdot C_i(x) + w_{i+1} \cdot c_{i+1}(x)}{W_i(x) + w_{i+1}}
\end{equation}

提取 Mesh 后，将颜色体积中对应顶点位置的颜色值赋给 Mesh 的顶点颜色。

\subsection{实现}

颜色融合（在 \texttt{integrate} 中）：
\begin{lstlisting}
if color_im is not None:
    px = pix_x[valid_idx]
    py = pix_y[valid_idx]
    new_color = color_im[py, px, :]
    c_old = self.color_vol[vx, vy, vz]
    self.color_vol[vx, vy, vz] = \
        (w_old[:, None] * c_old + obs_weight * new_color) \
        / w_new[:, None]
\end{lstlisting}

顶点着色（在 \texttt{demo.py} 中）：
\begin{lstlisting}
verts_idx = np.round(
    (verts - tsdf_vol._vol_origin) / tsdf_vol.voxel_size
).astype(int)
verts_idx = np.clip(verts_idx, 0,
                    np.array(tsdf_vol._vol_dim) - 1)
vert_colors = tsdf_vol.color_vol[
    verts_idx[:, 0], verts_idx[:, 1], verts_idx[:, 2]]
vert_colors = vert_colors[:, ::-1].astype(np.uint8)
\end{lstlisting}
