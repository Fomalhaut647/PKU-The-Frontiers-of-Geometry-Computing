\section{方法概述}
% =========================================================================

本次作业实现了基于 MLP（多层感知机）的隐式表面重建方法。网络以空间查询点坐标为输入，输出该点的符号距离函数（SDF）值。训练完成后，在均匀格点上计算 SDF，再用 Marching Cubes 算法提取零等值面，得到重建表面。

同时实现了拓展任务：基于 Fourier Feature 的位置编码，将查询点坐标先映射到高维频率空间，再输入 MLP，以提升对高频细节的表达能力。

% =========================================================================
\section{神经网络模型与方法细节}
% =========================================================================

\subsection{基础模型：Vanilla MLP}

\textbf{网络结构：}8 层全连接网络，每层宽度 256，激活函数为 ReLU，第 4 层处引入跳跃连接（Skip Connection），将输入坐标拼接到第 4 层的输入特征上。结构如下：

\begin{equation}
  h_0 = \text{ReLU}(W_0 \, q + b_0)
\end{equation}
\begin{equation}
  h_i = \text{ReLU}(W_i \, h_{i-1} + b_i), \quad i = 1,2,3
\end{equation}
\begin{equation}
  h_4 = \text{ReLU}(W_4 \, [h_3;\, q] + b_4)  \quad \text{（跳跃连接）}
\end{equation}
\begin{equation}
  h_i = \text{ReLU}(W_i \, h_{i-1} + b_i), \quad i = 5,6,7
\end{equation}
\begin{equation}
  \tilde{F}(q) = W_{\text{out}} \, h_7 + b_{\text{out}}
\end{equation}

输入维度为 3（$(x, y, z)$ 坐标），输出维度为 1（SDF 值）。

\textbf{参数量：}
\begin{itemize}[noitemsep]
  \item 第 0 层：$3 \times 256 + 256 = 1{,}024$
  \item 第 1–3 层（各）：$256 \times 256 + 256 = 65{,}792$（共 3 层）
  \item 第 4 层（跳跃）：$(256+3) \times 256 + 256 = 66{,}048$
  \item 第 5–7 层（各）：$256 \times 256 + 256 = 65{,}792$（共 3 层）
  \item 输出层：$256 \times 1 + 1 = 257$
\end{itemize}
\textbf{总参数量：}$\mathbf{462{,}593}$

\subsection{拓展模型：Fourier Feature MLP}

\textbf{位置编码：}参考 Tancik 等人 \cite{fourier2020}，对输入坐标 $q \in \mathbb{R}^3$ 进行随机 Fourier 特征映射：

\begin{equation}
  \gamma(q) = \left[\sin(2\pi \mathbf{B} q),\; \cos(2\pi \mathbf{B} q)\right]^\top \in \mathbb{R}^{2L}
\end{equation}

其中 $\mathbf{B} \in \mathbb{R}^{L \times 3}$ 为固定随机矩阵，每个元素从 $\mathcal{N}(0, \sigma^2)$ 采样。
本实验取 $L = 256$，$\sigma = 10$，编码维度为 $2 \times 256 = 512$。

\textbf{网络结构：}与 Vanilla MLP 相同（8 层，宽度 256，跳跃连接），但输入维度改为 512（Fourier 编码后的维度）。

\textbf{总参数量：}
\begin{itemize}[noitemsep]
  \item Fourier 矩阵 $\mathbf{B}$：$256 \times 3 = 768$（不参与训练，仅作缓冲区）
  \item 第 0 层：$512 \times 256 + 256 = 131{,}328$
  \item 第 4 层（跳跃）：$(256+512) \times 256 + 256 = 196{,}864$
  \item 其余层与 Vanilla 相同
\end{itemize}
\textbf{总可训练参数量：}$\mathbf{723{,}201}$

\subsection{损失函数}

\begin{equation}
  \mathcal{L} = \frac{1}{|B|}\sum_{q_i \in B} \left[
    \left(\tilde{F}(q_i) - F(q_i)\right)^2
    + \lambda \left\|\nabla_{q_i}\tilde{F}(q_i) - N(q_i)\right\|^2
  \right]
\end{equation}

其中 $F(q_i)$ 为真实 SDF 值，$N(q_i)$ 为真实 SDF 梯度（单位法向量），$B$ 为随机采样的 mini-batch，$\lambda$ 为梯度损失权重（本实验取 $\lambda = 0.1$）。

梯度 $\nabla_{q_i}\tilde{F}$ 通过 \texttt{torch.autograd.grad} 对输入坐标求导计算。

\subsection{设计说明}

\begin{itemize}
  \item \textbf{跳跃连接：}参照 DeepSDF~\cite{deepsdf2019} 的做法，在第 4 层引入跳跃连接，帮助梯度流动、防止深层网络退化。
  \item \textbf{余弦退火：}使学习率平滑衰减，后期精细优化。
  \item \textbf{随机采样：}每步随机采样 16{,}384 个点（约占总样本 1.8\%），避免内存瓶颈，同时提供足够多样的梯度信号。
  \item \textbf{梯度损失权重：}$\lambda = 0.1$ 在 SDF 拟合精度和梯度（法向）一致性之间取得平衡。
\end{itemize}

\subsection{结果分析}

两种方法均能重建出与 Ground Truth 外形相近的飞机形状，整体轮廓（机身、机翼、尾翼）可辨。

\textbf{Vanilla MLP 的特点：}
\begin{itemize}
  \item SDF 误差极小（$\mathcal{L}_\text{sdf} < 0.002$），零等值面位置准确；
  \item 梯度误差较大（$\mathcal{L}_\text{grad} \approx 0.11$--$0.17$），表面法向精度不足；
  \item 重建表面光滑，但高频细节（翼尖、引擎舱等）被磨平——这正是 MLP 频谱偏置（spectral bias）的体现。
\end{itemize}

\textbf{Fourier MLP 的特点：}
\begin{itemize}
  \item 梯度误差显著降低（$\mathcal{L}_\text{grad} \approx 0.019$--$0.065$，约为 Vanilla 的 1/3--1/6），说明表面法向预测更准确；
  \item SDF 绝对误差略有增大，但更多格点对应表面真实法向；
  \item 部分形状（Shape 1）重建顶点数更多，表面细节更丰富；Shape 2--5 由于数据分布较集中，顶点数略减，但法向质量更好。
\end{itemize}

\section{拓展任务：Fourier Feature 对比分析}
% =========================================================================

\subsection{原理}

深层 MLP 具有频谱偏置（spectral bias）\cite{rahaman2019spectral}：在训练早期，网络倾向于先拟合低频成分，高频函数的学习非常缓慢。对于 SDF 重建任务，这意味着 Vanilla MLP 容易生成过于光滑的表面，丢失翼尖、引擎槽等高频几何特征。

Fourier Feature 方法通过随机位置编码：
\begin{equation}
  \gamma(q) = \left[\sin(2\pi \mathbf{B} q),\; \cos(2\pi \mathbf{B} q)\right]^\top
\end{equation}
将输入映射到一个内积核函数空间：
\begin{equation}
  k(q, q') = e^{-\frac{\pi^2 \sigma^2}{2}\|q-q'\|^2}
\end{equation}
即高斯 RBF 核。当 $\sigma$ 较大时，核函数带宽窄、支撑高频分量，使得 MLP 能够高效拟合高频细节，克服频谱偏置。

\subsection{实验结果对比}

从表 2 可以看出：

\begin{itemize}
  \item \textbf{梯度损失（$\mathcal{L}_\text{grad}$）：}Fourier MLP 在所有 5 个形状上均显著优于 Vanilla MLP，降幅约 50\%--85\%。这直接验证了 Fourier Feature 对高频分量（法向）的提升作用。

  \item \textbf{SDF 损失（$\mathcal{L}_\text{sdf}$）：}Vanilla MLP 在 SDF 绝对值上略优（Shape 2, 3, 5）。这符合预期：高频映射引入更多自由度，网络更容易在 SDF 绝对值上产生波动，但换取了更好的梯度方向。

  \item \textbf{总损失：}4/5 形状上 Fourier MLP 总损失更低，综合性能更好。
\end{itemize}

\subsection{从可视化图像中观察}

（参见图 \ref{fig:overview} 及图 \ref{fig:shape1}--\ref{fig:shape5}）

\begin{itemize}
  \item Vanilla MLP 重建的表面整体更"圆润"，边缘过渡更模糊；
  \item Fourier MLP 重建的表面在翼身连接处、尾翼边缘处呈现出更锐利的棱线，法向方向变化更陡峭，视觉上细节更丰富；
  \item 在 Shape 1（顶点数最多的形状）上，两者差异最为显著，Fourier 重建的机翼轮廓更清晰。
\end{itemize}

\subsection{局限性}

\begin{itemize}
  \item $\sigma = 10$ 时 Fourier 特征覆盖的频率范围已经较高，但仍受限于 $128^3$ Marching Cubes 分辨率，无法表现比格点间距（约 0.009 m）更细的特征。
  \item 部分 Fourier 重建网格（Shape 1、3、5）Euler 特征数非零，说明存在拓扑噪声；这是高频拟合与有限 SDF 样本密度之间的权衡。
  \item 两种方法均采用相同的训练轮数和超参数，实际上 Fourier MLP 可能从更多轮训练或更小的 $\sigma$ 中受益更多。
\end{itemize}

% =========================================================================
\section{结论}
% =========================================================================

本次作业成功实现了基于 MLP 和 Fourier Feature MLP 的 SDF 隐式表面重建方法：

\begin{itemize}
  \item 两种方法均能在约 40 秒内完成 2000 轮训练，并快速提取重建 mesh；
  \item Vanilla MLP 提供稳定、光滑的重建，SDF 绝对值拟合精度高；
  \item Fourier Feature MLP 通过位置编码突破频谱偏置，法向预测精度显著提升，重建表面的高频细节更丰富；
  \item 在绝大多数形状上，Fourier MLP 总损失更低，综合重建质量更优。
\end{itemize}
